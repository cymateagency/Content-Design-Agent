# Content-Design-Agent

## Client work

- If the env var `CLIENT` is set (`run-agent.sh CLIENT=<slug>`), the client's brain at `/home/box/brains/clients/<slug>/` (`INDEX.md`, `brand.md`, `content.md`, `seo.md`, `preferences.md`) overrides this repo's Cymate house style for that job.
- Never use Cymate brand (orange #FD5E02, Anton, the Cymate logo) or Cymate internal data in client work, never read other clients' folders, and end with a `CLIENT-FACTS:` block instead of editing the brain.
