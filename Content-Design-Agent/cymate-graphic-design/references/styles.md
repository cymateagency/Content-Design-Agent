# Style library

The approved look for new work is in `inspiration.md` (seven reference posts with the touch to borrow from each). Lean on those directions often, mixed with the styles below.

Pick the style that makes the idea land fastest, and vary it: don’t use the same style twice in a row (check the Style column in `content-log.md`). Each style has a template in `templates/`; the example content in each is a placeholder concept.

## More directions to build from the same parts
- **Object hero**: one realistic object carries the idea (a receipt of wasted sends, a boarding pass to "Pipeline", a warning label on a bad list, a parking ticket for a bounced email).
- **Search / autocomplete**: "why is my cold email…" with honest autocomplete suggestions (like What We Do).
- **Chat thread**: a prospect conversation in DM bubbles that goes from cold to booked.
- **Checklist / scorecard**: tick boxes the reader scores themselves on (like Put a Finger Down).
- **Big type only**: three words, huge display face, one texture. Works best as a cover.
- **Split screen**: two halves (wrong vs right, them vs you, 2015 vs 2026).

## Making it stop the scroll
- One hero element takes 40–60% of the canvas; everything else supports it.
- The headline opens a gap ("You’re measuring the wrong metric") or names the reader’s pain.
- Main read is under ~12 words; detail goes in the caption.
- Contrast check at thumbnail size: shrink the PNG to ~300 px wide and make sure the headline still reads.
- Fun is welcome: a wink in the copy, a playful prop, motion implied by tilt and overlap.
